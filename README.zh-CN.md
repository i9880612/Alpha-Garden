# Alpha Garden

[English](README.md) | **简体中文**

**持续探索新的公式，让有潜力的想法得到进一步验证。**

Alpha Garden 是一个面向 WorldQuant BRAIN 的自动化公式研究项目。你确定研究规模和运行轮数，系统负责寻找公式、进行回测、比较结果，并围绕有价值的方向继续尝试。

它希望让研究形成积累：表现好的公式得到继续改进的机会，已经尝试过的结果为下一轮提供依据，暂时没有提升空间的合格公式也能保留下来。

![WorldQuant BRAIN 平台的已提交公式列表](assets/submitted-alphas.png)

## 它能帮你做什么

- **寻找新的研究方向。** 持续探索不同字段和公式结构，为后续研究补充新的起点。
- **改进已有公式。** 围绕有潜力的公式生成变化，交给真实回测验证，再决定哪些结果值得继续研究。
- **尝试解决相关性问题。** 对平台指出的自相关冲突进行有针对性的调整，比较相关性变化与表现上的代价。
- **整理研究成果。** 区分需要继续优化、可以准备提交和暂时保留的公式，并自动汇总已经提交成功的成果。

## 以 Spectacular 为目标

Alpha Garden 默认优先准备 **Spectacular** 级别的公式。评级由 WorldQuant BRAIN 给出，正式提交前还要通过平台的完整检查，包括自相关性检查。

已经合格、但评级还没有达到目标的公式，可以继续参加优化。每条公式最多有 **20 次变异机会**；如果出现表现更好的合格后代，就由后代接着研究，使用它自己的剩余机会。

机会用完后仍未达到目标的合格公式，会保留到合格表中，供以后按等级提交。被更优后代接替的合格公式也会保留，但只有自身 20 次机会已经用完的，才会参加按等级提交。

## 两种研究方式

| 你想做的事 | 使用方式 |
| --- | --- |
| 寻找新公式，同时改进已有方向 | 普通回测：结合探索、变异和自相关性治理 |
| 集中提升已经合格的公式 | 专项优化：围绕检查全部通过、评级不足且仍有机会的公式继续尝试 |

普通回测和专项优化共享每条公式的 20 次机会，切换方式不会重新计算。你可以安排一轮，也可以安排多轮连续运行；系统按实际可用候选推进。

## 日常使用

完成首次配置后，常用操作只需要几条命令：

| 想做什么 | 命令 |
| --- | --- |
| 先跑一轮看看结果 | `alpha-garden run` |
| 连续跑 5 轮 | `alpha-garden run 5` |
| 专门优化合格公式 | `alpha-garden run -opt` |
| 从 Spectacular 队列提交 2 条 | `alpha-garden submit 2` |
| 从合格表提交 2 条额度耗尽的 Good 公式 | `alpha-garden submit good 2` |

数量可以自行调整。按等级提交也支持 `average`、`excellent`、`inferior`；省略数量时处理本次符合条件的全部候选。

提交数量按**成功提交的条数**计算。单条复检不通过会跳过，候选不足时提前结束；结果尚未明确时先确认已有请求，不重复提交。

<details>
<summary>首次使用：安装与账号配置</summary>

需要 Python 3.11 或更高版本，以及可访问 WorldQuant BRAIN 的账号。在项目目录执行：

```powershell
python -m pip install --no-deps -e .
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

参照 [.env.example](.env.example) 填写 `.env` 中的账号范围和认证信息，然后初始化：

```powershell
alpha-garden init
```

已有配置和研究数据请保留。

## 看得见的研究过程

运行时可以直接看到当前进度，以及每条公式的来源、评级、关键指标和检查结果。基础回测显示“通过”后，还需要完成平台的提交检查。

提交成功的公式会自动汇成一份清单，方便回看已经积累的成果。清单只展示公式编号、提交时间和简要指标，不包含公式正文；账号配置、研究数据和结果清单不会随代码上传。

回测默认不会正式提交公式。你可以在查看成果后自行提交，也可以在开始运行时明确开启自动提交。运行中的常见请求故障有重试和恢复安排；需要处理账号问题或确认提交结果时，系统会保留已有进度并提示。
